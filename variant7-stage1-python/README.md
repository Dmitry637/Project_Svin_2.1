# Вариант №7 — этап 1 (Python)

Это отдельный проект только для первого этапа задания. Он читает параметры из INI-файла, проверяет их и выводит на экран в формате `ключ=значение`. На этом этапе программа **не загружает POM-файлы, не извлекает зависимости и не строит граф**.

## Параметры конфигурации

- `[package] name` — координаты пакета Maven в формате `groupId:artifactId`.
- `[package] version` — версия пакета.
- `[repository] location` — URL HTTP(S) или путь к локальному файлу/каталогу тестового репозитория.
- `[repository] mode` — `auto`, `local` или `remote`.
- `[visualization] graph_image` — имя файла изображения для будущего этапа.

## Запуск

Из корня распакованного проекта:

```bash
python main.py
python main.py --config config.ini
python -m unittest discover -s tests -v
```

Параметры пользователя находятся в `config.ini`. По умолчанию используется файл `tests/fixtures/test-repository.json`; его содержимое на этапе 1 не анализируется. Все ошибки конфигурации выводятся в `stderr`, приложение завершается с кодом 2.

Требуется Python 3.10 или новее. Установка сторонних библиотек не требуется.

## Структура

```text
src/       исходный код проверки INI
 tests/    модульные тесты и тестовый файл репозитория
main.py    точка входа этапа 1
config.ini пользовательская конфигурация
```
